# Wivue — 와이파이 장애 진단 및 대응 지원 시스템

[← 포트폴리오 목록](../README.md)

교내 와이파이 품질 문제를 파악하기 위해 네트워크 측정 데이터를 수집·저장하고, AI 기반 장애 진단과 알림을 제공하는 팀 프로젝트입니다.

- **개발 기간:** 2025년 8월 · 2주
- **팀 구성:** 5인
- **담당 역할:** DB 전체 설계·구현, 전체 API 및 배포 전 로컬 서버 개발, ERD·플로우차트 작성
- **사용 기술:** Python, Flask, MySQL
- **팀 저장소:** [Union-Summer-Project-2025](https://github.com/gmldbs3104/Union-Summer-Project-2025)

## 프로젝트 개요

라즈베리파이 센서가 측정한 와이파이 신호 강도, 지연시간, 속도 등의 데이터를 서버에 전달하고 MySQL에 저장합니다. 수집 데이터를 바탕으로 머신러닝 모델이 장애 원인을 진단하며, 장애 발생 시 Slack 알림으로 대응을 지원합니다.

하드웨어, 머신러닝, 서버, 데이터베이스 등으로 역할을 나누어 진행했습니다. 저는 데이터베이스와 API를 포함한 로컬 서버 개발을 맡았으며, 배포 전 단계까지 구현했습니다.

## 담당 범위

### DB 전체 설계·구현

네트워크 측정 데이터를 저장하고 API에서 조회·활용할 수 있도록 데이터베이스 전체를 설계하고 구현했습니다. ERD를 직접 작성해 데이터 구조와 관계를 정리하고, MySQL 데이터베이스를 서버와 연결했습니다.

### 전체 API 및 로컬 서버 개발

Flask를 사용해 프로젝트의 모든 API를 구현했습니다. 센서 측정 데이터를 받는 요청부터 저장 데이터 조회와 재예측 요청까지 로컬 환경에서 동작하는 서버 기능을 개발했습니다.

### 플로우차트·ERD 작성

데이터 수집과 처리 흐름을 플로우차트로, 데이터베이스 구조를 ERD로 정리했습니다. 설계 문서와 실제 서버·DB 구현을 함께 담당했습니다.

## 주요 API

아래는 팀 저장소 README에 명시된 주요 API입니다.

| 기능 | 메서드·경로 | 동작 |
|---|---|---|
| 서버 상태 확인 | `GET /` | 서버 실행 상태 확인 |
| 데이터 업로드 및 예측 | `POST /upload` | 측정 데이터 업로드와 예측 처리 |
| 최근 측정 데이터 조회 | `GET /readings` | 최근 저장된 측정 데이터 조회 |
| 특정 측정 데이터 재예측 | `POST /predict` | 측정 데이터 ID를 기준으로 재예측 요청 |

업로드 데이터에는 센서 식별자, 측정 시각, 신호 강도, 지연시간, 속도, 핑 타임아웃 여부 등이 포함됩니다. 요청·응답 예시는 [팀 저장소의 API 명세](https://github.com/gmldbs3104/Union-Summer-Project-2025#readme)에서 확인할 수 있습니다.
