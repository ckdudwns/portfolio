## 프로젝트 개요

사용자가 앱에서 기사를 읽고 추천 기능을 이용할 수 있도록 백엔드 서버와 모바일 앱을 연결한 프로젝트입니다.

저는 백엔드와 Flutter 앱을 함께 개발하며, 사용자 화면에서 발생한 요청이 서버로 전달되고 응답이 앱에 반영되는 흐름을 구현했습니다. 추천 알고리즘 자체의 개발은 다른 팀원이 담당했습니다.

## 담당 범위

### 백엔드 서버 개발

추천 알고리즘을 제외한 백엔드 전체를 담당했습니다. Python 기반 서버에서 앱이 사용하는 API를 구현하고, 앱과 서버 사이의 데이터 요청·응답을 처리했습니다.

### Flutter 앱 개발

Flutter와 Dart로 앱 화면과 기능을 개발하고 백엔드 API를 연결했습니다. 서버에서 전달받은 데이터를 앱에서 사용할 수 있도록 연동하는 작업을 담당했습니다.

### 앱·서버 연결 환경 구성

개발 중인 Flutter 앱에서 로컬 백엔드에 접근할 수 있도록 서버 주소와 포트를 설정했습니다. 연결 과정에서 겪은 어려움은 ngrok 주소를 사용해 해결했습니다.

## 문제 해결 경험 — Flutter 앱과 로컬 백엔드 연결

### 문제

Flutter 앱과 로컬 백엔드를 연동하는 과정에서 서버 주소와 포트를 설정하는 데 어려움을 겪었습니다. 로컬에서 실행한 서버를 앱에서 호출할 수 있도록 연결 경로를 구성해야 했습니다.

### 해결 과정

ngrok을 사용해 로컬 백엔드의 실행 포트로 요청을 전달하는 접속 주소를 만들었습니다. 이후 Flutter 앱의 API 요청 주소에 해당 ngrok 주소를 적용해 앱과 서버를 연결했습니다.

```text
Flutter 앱
    ↓ API 요청
ngrok 접속 주소
    ↓ 로컬 서버 포트로 전달
Python 백엔드
```

### 결과와 배운 점

ngrok 주소를 통해 앱과 로컬 백엔드를 연동했습니다. 이 과정에서 서버가 실행 중인 것뿐 아니라, 앱에서 접근할 수 있는 주소와 서버의 실행 포트를 올바르게 연결해야 한다는 점을 배웠습니다.

이 경험은 개발 환경에서의 앱·서버 연결에 해당하며, 운영 환경의 서버 배포와는 구분합니다.

## 프로젝트를 통해 얻은 경험

백엔드 API와 이를 사용하는 Flutter 앱을 함께 개발하면서 사용자 화면부터 서버 요청·응답까지 연결하는 과정을 경험했습니다. 특히 앱과 서버를 각각 구현하는 작업에 더해, 두 구성 요소가 실제로 통신할 수 있는 접속 환경을 설정하는 중요성을 익혔습니다.
