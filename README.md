# 차영준 | 개발 포트폴리오

게임 개발을 목표로, 백엔드 서버와 앱·게임을 구현하며 경험을 쌓고 있습니다. 데이터 수집·저장과 API 설계부터 사용자 화면과의 연동까지, 서비스가 동작하는 전체 흐름을 이해하고 구현하는 데 관심이 있습니다.

## 백엔드·앱 프로젝트

### Bind Edge AI — 모터 상태 모니터링 시스템

도서·섬 지역 회전설비의 진동·음향 데이터를 수집하고, 운영자가 이상 징후와 판정 근거를 원격으로 확인하는 **4인 팀 프로젝트**입니다.

- **개발 상태:** 진행 중
- **담당:** 프로젝트 기획 및 백엔드 전체 개발
- **기술:** Python, SQLite, AWS EC2, Caddy, systemd
- **주요 기여:** 센서 데이터 수집·검증 및 재전송 중복 방지, 이상 이벤트 상태 관리, 계정·장치 인증, 백업·복구

[상세 소개](projects/motor-diagnosis.md) · [팀 저장소](https://github.com/ckdudwns/MotorDiagnosis)

### Wivue — 와이파이 장애 진단 및 대응 지원 시스템

교내 와이파이 품질 문제를 파악하기 위해 네트워크 측정 데이터를 수집하고, AI 기반 장애 진단과 알림을 제공하는 **5인 팀 프로젝트**입니다.

- **개발 기간:** 2025년 8월 · 2주
- **담당:** DB 전체 설계·구현, 전체 API 및 배포 전 로컬 서버 개발
- **기술:** Python, Flask, MySQL
- **주요 기여:** ERD·플로우차트 작성, 데이터 저장 구조 구현, 측정 데이터 업로드·조회·재예측 API 개발

[상세 소개](projects/wivue.md) · [팀 저장소](https://github.com/gmldbs3104/Union-Summer-Project-2025)

### 기사리딩앱 — 기사 읽기 서비스

기사 읽기와 추천 기능을 제공하는 **4인 팀 프로젝트**로, 백엔드 서버와 Flutter 앱 개발을 담당했습니다.

- **개발 기간:** 2026년 4~5월
- **담당:** 백엔드 및 Flutter 앱 개발
- **기술:** Python, Flutter, Dart, ngrok
- **주요 기여:** 서버 API 구현, Flutter 앱 개발, ngrok을 활용한 앱·로컬 백엔드 연동
